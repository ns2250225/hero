# 像素勇者：无尽怪物潮（Pixel Heroes: Endless Horde）

2D 像素风横版阵地防守 / 放置战斗 / Roguelike / 英雄收集养成网页游戏。
纯前端实现：**无后端、无登录、无外部美术与音频资源**，可离线运行、可静态部署。

技术栈：Vue 3 + TypeScript + Phaser 3 + Pinia + Vite

## 游戏特色

- 🛡️ **阵地防守**：在左侧自由布置 12 名职业各异的像素英雄，抵御从右侧涌来的无尽怪物潮
- ⚔️ **自动战斗**：英雄自动索敌、普攻、释放技能；近战阻挡、倒下复活，解放双手
- 🎲 **Roguelike 成长**：每波三选一升级卡、4 档稀有度、刷新与锁定策略，构筑随缘也随心
- 🤝 **羁绊与遗物**：12 组英雄羁绊、22 件遗物，激活特效全屏演出
- 🗡️ **装备系统**：6 部位 × 6 品质 × 25 种词条，掉落、锻造、自动装备一站搞定
- 👹 **Boss 战**：8 个 Boss、12 种 Boss 技能、狂暴阶段，配震屏与全屏警告
- 🌏 **全程序化生成**：像素美术、图标、音效、BGM 全部由代码实时生成，零外部资源
- 📱 **PWA 离线可玩**：Service Worker 缓存，添加到主屏幕后断网也能玩，支持移动端触屏

## 环境要求

- Node.js ≥ 18（推荐 20+）
- npm ≥ 9

## 快速开始

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 类型检查 + 生产构建，输出到 dist/
npm run build:fast # 跳过类型检查的快速构建
npm run preview    # 本地预览构建产物 http://localhost:4173
npm run typecheck  # 仅运行 TypeScript 类型检查
```

### 静态部署

`vite.config.ts` 使用 `base: './'`，`dist/` 可以直接放到任意静态托管：

- **GitHub Pages**：把 `dist/` 推到 `gh-pages` 分支，或使用 Pages Action 上传 `dist`。
- **Cloudflare Pages**：构建命令 `npm run build`，输出目录 `dist`。

首次打开后 Service Worker 会缓存应用外壳与构建资源，之后可离线游玩（PWA，可“添加到主屏幕”）。

## 操作

| 操作 | 说明 |
|---|---|
| 鼠标/手指拖动英雄 | 在左侧布置区自由调整站位（绿色/红色预览表示是否合法） |
| 单击英雄 → 单击目标位置 | 点击式移动英雄 |
| 点击底部英雄头像 | 查看英雄属性、技能与冷却 |
| 空格 | 暂停 / 继续 |
| F | 切换倍速 ×1 / ×2 / ×4 |
| 1 / 2 / 3 | 选择升级卡片 |
| H | 打开“冒险圣所”（遗物、羁绊、技能、防线、被动） |
| P | 暂停菜单（自动布阵、自动升级策略、保存并退出） |

## 目录结构

```text
src/
├── views/        主菜单、选关、战斗、图鉴、装备、天赋、成就、设置、存档
├── components/   HUD、升级卡片、事件、Boss 血条、结算/暂停/详情弹窗
├── game/
│   ├── scenes/   BootScene（生成全部像素纹理）、BattleScene（战斗主循环）
│   ├── entities/ Hero、Enemy/Boss、Projectile/Zone/特效、Summon、伤害数字
│   ├── systems/  技能、索敌、伤害
│   ├── managers/ GameManager、PoolManager、AudioManager
│   ├── art/      像素栅格、图标、角色/怪物/Boss/特效生成器
│   └── utils/    随机数、空间网格、数值平衡、属性计算、装备、本局状态、自动升级
├── data/         英雄、怪物、Boss、技能、装备、遗物、羁绊、地图、波次、事件、天赋、成就、升级卡
├── stores/       playerStore（永久数据）、settingsStore、uiStore
├── services/     SaveService（存档/离线收益）、RunController（开局/结算）
└── types/        hero / enemy / skill / game
```

所有内容都是数据驱动的：新增英雄、技能、怪物或遗物只需要在 `src/data/` 中添加配置。
